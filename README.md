# GASTU - Maqueta Web

Este repositorio contiene la maqueta del sistema de gestión financiera **GASTU**, desarrollada en HTML, CSS y JavaScript puros (con opción de integrar PHP más adelante). Representa la estructura visual y funcional del sistema antes de su implementación real.

---

## 📁 Estructura de carpetas
```
maqueta_GASTU/
│
├── assets/ # Archivos estáticos del proyecto
│ ├── css/ # Hojas de estilo
│ │ └── styles.css # Estilo global del sitio
│ ├── img/ # Imágenes (logos, íconos, ilustraciones)
│ └── js/ # Lógica de comportamiento
│ └── main.js # Funciones generales (eventos, importaciones, etc.)
│
├── components/ # Componentes HTML reutilizables
│ ├── header.html # Encabezado del sitio
│ ├── navbar.html # Navegación lateral o superior
│ └── footer.html # Pie de página
│
├── views/ # Vistas individuales (a completar)
│ ├── dashboard.html # Panel principal del usuario
│ ├── login.html # Pantalla de inicio de sesión
│ ├── register.html # Registro de usuarios
│ └── index.html # Landing page inicial del proyecto
│
├── README.md # Documentación del proyecto
```

### 📘 Descripción de carpetas y archivos

- **`assets/`** – Archivos estáticos.
  - `css/` → Hojas de estilo globales.
  - `img/` → Imágenes como íconos, logos, etc.
  - `js/` → Scripts JS (validaciones, carga de componentes, etc.).
- **`components/`** – Fragmentos HTML reutilizables como `navbar`, `footer`, `header`.
- **`views/`** – Vistas HTML individuales que representan pantallas del sistema.
- **`README.md`** – Documentación del proyecto.
